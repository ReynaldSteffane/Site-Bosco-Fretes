# Site-Bosco-Fretes

Site institucional da **Bosco Fretes**, empresa de transporte, logística e fretes para todo o Brasil.

## Estrutura

```
index.html        página principal (início, serviços, sobre nós, avaliações, galeria, contato)
estilo.css        visual de todo o site
blog/             um artigo por página
imagens/          logo e demais imagens
```

## Como visualizar

Extraia o ZIP e abra o `index.html` no navegador. Mantenha as pastas e arquivos juntos, do jeito que estão.

## Como alterar

- **Cores, tamanhos e layout:** `estilo.css`
- **Textos e seções da página principal:** `index.html`
- **Novo artigo no blog:** copie um arquivo da pasta `blog/`, troque o texto e adicione o link em `index.html`, na seção Blog.

## Pendências

- Colocar fotos reais na galeria
- Adicionar o link do perfil no Google e a nota média
